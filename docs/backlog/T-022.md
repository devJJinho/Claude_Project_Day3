# T-022: 초대 대기 알림 UI(배지)

> 문서 기준 backlog 스냅샷: sourceHash a816a52d678ed6d3…, 이 태스크의 현재 status: **todo**

## 목적

T-021의 승인/거절 API 완성 후, invited 상태의 초대 대기 중인 항목이 있을 때 이를 사용자에게 알리기 위한 배지 UI를 구현합니다.

## 쉬운 설명

네비게이션 바 또는 대시보드에 배지("초대 대기 중: 2개" 등)를 표시하여 사용자가 확인하지 않은 초대가 있음을 알립니다.

## 필요한 입력

- T-021 (초대 승인/거절 API)

## 결과물

- InvitationBadge 또는 비슷한 컴포넌트
- 네비게이션 바에 표시

## 선행 작업

- T-021

## 수행 순서 (권장)

1. couple_members에서 status='invited'인 개수 조회
2. 개수 > 0이면 배지 표시
3. 클릭 시 초대 목록 페이지로 이동

## done_when 확인 방법

- 초대 대기 중일 때 배지가 표시되는가?
- 초대를 수락하면 배지가 사라지는가?
