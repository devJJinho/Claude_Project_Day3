# T-002: Tailwind CSS 설정

> 문서 기준 backlog 스냅샷: 최신 sourceHash 미확인 (접근 제한), 이 태스크의 현재 status: **done**
> (이 문서가 존재한다고 해서 이 태스크의 실제 개발이 끝난 것은 아닙니다.)

## 목적

개발요청서.md의 H. UX/디자인 섹션에서 "디자인/브랜드 톤: 참고 레퍼런스 없음 — 개발자 재량"으로 정해진 후, Tailwind CSS를 사용하여 반응형 웹 스타일링 기반을 확립합니다.

## 쉬운 설명

Tailwind CSS를 프로젝트에 설치하고 설정하여, 빠르게 UI를 만들고 스타일을 적용할 수 있는 환경을 준비합니다.

## 필요한 입력

- T-001이 완료되어 Next.js 프로젝트가 존재할 것
- Tailwind 공식 설치 가이드 참고

## 결과물

- `tailwind.config.js` 파일
- `postcss.config.js` 파일
- `globals.css` 또는 글로벌 스타일 파일에 Tailwind 지시문(`@tailwind` 등) 추가
- 컴포넌트에서 Tailwind 클래스를 바로 사용 가능한 상태

## 선행 작업

- T-001 (Next.js 프로젝트 초기화)

## 수행 순서 (권장)

1. `npm install -D tailwindcss postcss autoprefixer` (또는 Next.js 통합 설치)
2. `npx tailwindcss init -p` 실행
3. `tailwind.config.js`의 `content` 경로를 `'./app/**/*.{js,ts,jsx,tsx}'` 등으로 설정
4. 글로벌 스타일에 `@tailwind base; @tailwind components; @tailwind utilities;` 추가
5. 테스트: 간단한 Tailwind 클래스를 사용하여 스타일이 적용되는지 확인

## done_when 확인 방법

- `npm run build`가 Tailwind CSS를 포함하여 성공하는가?
- 개발 서버에서 Tailwind 클래스가 정상 작동하는가 (예: `className="bg-blue-500"` 테스트)?
- 빌드 결과물에서 CSS 파일이 생성되는가?
