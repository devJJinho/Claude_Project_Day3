## 쉬운 설명

Vercel(Next.js 만든 회사의 호스팅 서비스)에 프로젝트를 연결하여, GitHub 푸시할 때마다 자동으로 배포되도록 설정합니다.

## 필요한 입력

- Vercel 계정 (vercel.com)
- GitHub 리포지토리와의 연결 권한
- T-001 완료 (Next.js 프로젝트)

## 결과물

- Vercel 프로젝트 생성 (프로덕션 URL 발급)
- GitHub ↔ Vercel 자동 배포 연결 (git push → 자동 build & deploy)
- `vercel.json` 설정 (필요시)
- 환경변수 연결 (`.env` → Vercel dashboard)

## 선행 작업

- T-001 (Next.js 프로젝트 초기화)

## 수행 순서 (권장)

1. vercel.com에서 GitHub/GitLab 계정으로 로그인
2. "Import Project" → GitHub 리포지토리 선택
3. 프로젝트 이름 및 환경변수 입력 (NEXT_PUBLIC_SUPABASE_* 등)
4. "Deploy" 클릭
5. Vercel 배포 URL 확인
6. GitHub main 브랜치 푸시 시 자동 배포 확인
