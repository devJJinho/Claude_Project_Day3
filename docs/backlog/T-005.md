Supabase의 기본 `auth.users` 테이블과 연결되어, 사용자 추가 정보(닉네임, 프로필 사진 등)를 저장합니다.

## 결과물

- `profiles` 테이블 생성
  - `id` (uuid, primary key, auth.users와 연결)
  - `display_name`, `avatar_url` (프로필 정보)
  - `created_at`, `updated_at` (타임스탬프)
- RLS 정책 (사용자 자신의 프로필만 조회/수정 가능)
- `handle_new_user` 트리거 (회원가입 시 자동으로 profile 레코드 생성)

## 선행 작업

- T-003 (Supabase 프로젝트 생성)

## 수행 순서 (권장)

1. `npx supabase migration new create_profiles_table` 실행
2. 생성된 마이그레이션 파일에서:
   - `create table profiles (...)` 작성
   - `create trigger handle_new_user ...` 작성 (auth 연결)
3. `npx supabase db push` 실행해 마이그레이션 적용
4. Supabase 대시보드에서 `profiles` 테이블 확인
