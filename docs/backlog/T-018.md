# T-018: 커플 연결 - 초대 코드 생성 API

> 문서 기준 backlog 스냅샷: sourceHash a816a52d678ed6d3…, 이 태스크의 현재 status: **todo**

## 목적

개발요청서.md의 A. 계정 및 협업 모델 "부부 참여 구조: 각자 개별 계정으로 가입 후 '커플 연결'"에 따라, 사용자가 배우자를 초대하기 위한 초대 코드를 생성하는 API를 구현합니다.

## 쉬운 설명

사용자가 "배우자 초대" 버튼을 클릭하면 고유한 초대 코드가 생성되고, 이를 배우자와 공유하여 커플을 연결합니다.

## 필요한 입력

- T-006 (couples 테이블)
- T-017 (profile 자동 생성)

## 결과물

- `generateInvitationCode()` 서버 액션 또는 API 엔드포인트
- 초대 코드는 고유하며, 시간 제한 없음 (개발요청서에 기한 명시 없음)

## 선행 작업

- T-006, T-017

## 수행 순서 (권장)

1. couples 테이블에 invitation_code 필드 추가 (있으면 생략)
2. generateInvitationCode 서버 액션 구현
3. UUID 또는 짧은 랜덤 코드 생성

## done_when 확인 방법

- 초대 코드가 생성되는가?
- 같은 사용자가 다시 호출했을 때 새 코드가 생성되는가?

## 확인 질문

초대 코드 형식(UUID vs 숫자 vs 알파벳)이 정해지지 않았습니다.
