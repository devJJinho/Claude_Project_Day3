## 목적

개발요청서.md의 A. 계정 및 협업 모델 "추가 참여자 초대: 소셜 계정을 지정한 초대 + 초대받은 사람의 승인 필요"에 따라, 커플 외 추가 참여자(웨딩플래너, 가족, 친구)를 초대하는 API를 구현합니다.

## 쉬운 설명

사용자가 특정 사람의 이메일(또는 소셜 ID)을 지정하여 초대를 발송합니다. 초대받은 사람은 이를 수락하거나 거절할 수 있습니다.

## 필요한 입력

- T-006 (couples 테이블)
- T-017 (profile 자동 생성)

## 결과물

- `inviteParticipant()` 서버 액션 또는 API 엔드포인트
- couple_members 테이블에 status='invited' 레코드 생성

## 선행 작업

- T-006, T-017

## 수행 순서 (권장)

1. 초대할 사람의 이메일/소셜 ID 입력 폼 작성
2. inviteParticipant 서버 액션 구현
3. couple_members에 status='invited' 레코드 생성
4. 선택: 초대 알림 발송 (이메일 또는 인앱)

## done_when 확인 방법

- 초대가 생성되는가?
- invited 상태로 couple_members에 저장되는가?
